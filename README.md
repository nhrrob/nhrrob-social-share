# NHR Social Share

Share each post where its readers are, from WordPress, without a service in
between, and see which way of sharing brings them back.

Nothing is built in this repository yet. The scope is in
[`.ai/PRD.md`](.ai/PRD.md) and the work is in the issues, R&D first. The code
runs today in the blog's site plugin (nhrrob/nazmulrobin_blog) and moves here
for 0.1.
